## Page 1

Vendor Comparison Report
This report compares three logistics vendors evaluated during the March procurement cycle. Scores reflect a
weighted rubric across cost, reliability, and support responsiveness.
Method
Each vendor supplied reference customers and a 90-day pilot window. Reliability was measured as the fraction
of shipments delivered within the promised window. Support responsiveness was measured as median first-
response time on priority tickets.
Findings
Vendor B led on reliability at 97.1 percent, while Vendor A offered the lowest landed cost per unit. Vendor C
trailed on both axes but provides the only same-day option in the West region.
Recommendation
Proceed to contract negotiation with Vendor B for core volume, retaining Vendor C for same-day West-region
overflow. Revisit pricing with Vendor A at the six-month checkpoint.
